  1. Abra o Google AI Studio e entre com sua conta Google.
  2. Clique em Create API key (é grátis, não precisa de cartão).
  3. Copie a chave e cole aqui embaixo.

2. Cole a chave

🔒 A chave fica salva só neste navegador e é enviada apenas para o Google. Ela não vai para o backup nem para nenhum outro lugar.
